## How I work

- **Grammar + gate.** If a brief or diagram kit cannot be linted, it is not finished.
- **Strategy labels, not fake ownership axes.** Own / OSS / AWS is not a universal legend.
- **Fictional public samples.** Teaching systems stay invented. No customer brands in public trees.
- **Local-first agent tools.** CLI and MCP before dashboards.
